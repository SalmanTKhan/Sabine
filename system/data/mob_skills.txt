// Sabine
// Mob Skill Database
//
// Slim subset of eAthena's `db/mob_skill_db.txt`. Each row attaches a
// skill to a mob class; the reactive AI's combat tick consults this
// table, rolls the per-tick rate, and casts via the standard skill
// handler registry. Multiple entries per mob are allowed — the AI
// rolls each one independently per tick.
//
// Fields:
//   mobId, skillId        — mob class id, SkillId enum name
//   level                  — skill level for the cast
//   rate                   — per-100 chance per AI tick (default 50)
//   cooldownMs             — minimum ms between casts of this skill
//   target                 — "target" / "self" (default "target")
//
// Omitted from eAthena: state / condition / val1-5 / emotion / chat —
// the v1 schema treats every entry as "always-true while in combat".
//---------------------------------------------------------------------------
